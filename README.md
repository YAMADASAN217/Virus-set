# Virus-set Script by PeppeR

### Virus-setとはなんですか？
このウイルスは、PeppeRの手によって製作されたウイルスです。このウイルスは1日で製作されたため、バグが多発する場合があります。
### 使い方は？
エラーが大量に出てくる「Viral-Cleaner.exe」と無理やりPCを落とす「KaniRaaaaaaaaaaaaaaaaaamen.exe」がセットで入っています。このプログラムには危険なコードが含まれているため、仮想マシンまたは未使用のデバイスでテストすることをお勧めします。いかなる場合でも、物理ハードウェア上でこのプログラムを実行しないでください。予期せぬ損傷を引き起こす可能性があります。いかなる損害についても、私は責任を負いません。インストーラーはないため、実行するだけでPCを破壊できます。
### ちなみにこれはジョークウイルスです。再起動すれば修復できます。しかしKaniRaaaaaaaaaaaaaaaaaamen.exeは何回か再起動する必要があります
